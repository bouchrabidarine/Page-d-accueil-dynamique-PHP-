# Installation de PHP et préparation de l'environnement local

## 1. Vérification de PHP

Commande exécutée :

```bash
php -v
```

Résultat : PHP 8.5.12 est installé et fonctionne correctement.

## 2. Démarrage du serveur local

Commande exécutée :

```bash
php -S localhost:8000
```

## 3. Validation dans le navigateur

Adresse utilisée :

```text
http://localhost:8000/test-serveur.php
```

Résultat attendu :

Le serveur PHP fonctionne correctement !

## 4. Arrêt du serveur

Commande utilisée :

```text
Ctrl + C
```
